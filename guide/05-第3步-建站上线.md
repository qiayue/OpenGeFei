# 第 3 步：建站上线

上一步你手里已经有了一个验证过的关键词。这一步要做的事情很朴素：**把这个关键词变成一个用自己域名能打开的网站**，并且在上线当天把「让谷歌知道它存在、让你看得到它的数据」的那几件事一次做完。

完成标准是这样的：

- 在浏览器里输入 `https://你的域名`，能打开一个页面，页面在回答这个关键词背后的需求；
- 不带 www 和带 www、http 和 https，最后都会跳到同一个网址；
- 网站已经添加进 Google Search Console（下面简称 GSC）并提交了 sitemap，也装好了统计代码；
- 有 robots.txt，有 About、Contact、Privacy 这类基础页。

第一个站的目标是**最快两小时上线**。哥飞演示过注册 MemoryTest.io 这个域名、用 Claude 生成页面、部署到 Vercel，从 11:38 注册域名到 12:40 网站能访问，一边截图写文章一边做，一个小时搞定，他说如果只是做网站，半小时内肯定能搞定（[如何半小时上线一个小游戏网站](../articles/03-build/2024-11-12-【哥飞实操教学】如何半小时上线一个小游戏网站.md)）。你第一次做，留两个小时足够。

为什么要这么快？哥飞在 [新词来了时，请抓住先发优势，尽快发布](../articles/02-keywords/2025-03-18-新词来了时，请抓住先发优势，尽快发布.md) 里说：支付和登录不是网站刚上线时必须要接入的，**网站最简形态可以只是一个 html 文件**；尽快发布，比尽善尽美更好。第一个站如果拖成一个月的「大工程」，很可能就烂尾了。

## 你需要准备

- **一个能在海外平台付款的支付方式**：买域名要用，国外注册商一般支持信用卡或 PayPal（以各家最新支付方式为准）。
- **一个谷歌账号**：用来登录 GSC 和 Google Analytics。
- **一个 GitHub 账号**：存放网站代码。
- **一个 Vercel 账号**（或 Cloudflare 账号）：托管网站，不用买服务器。
- **一个 Cloudflare 账号**：管理域名解析。
- **一个 AI 编程工具**：Claude、ChatGPT 这类对话工具就能做单页网站；想长期迭代可以用 Cursor、Claude Code 之类的编辑器。
- **时间**：第一次两个小时左右；熟练后一个站半小时到一小时。
- **钱**：一个常见后缀的域名一年几美元到十几美元；托管用免费套餐起步（截至 2026 年 9 月，Vercel 和 Cloudflare 都有免费套餐，额度与条款以官方最新说明为准）。

## 步骤

### Step 1：确定域名——优先用关键词注册

哥飞的一贯建议是**用关键词注册域名**。他举过字数统计工具的例子：搜 Word Counter 和 Word Count，排在前面的网站里，wordcounter.net、wordcounter.io、wordcount.com 基本都是「域名注册什么关键词，就拿到了什么关键词的搜索结果」，他说这有点「求仁得仁」的意思（[以月访问量760万的字数统计工具网站告诉你为什么要用关键字为域名](../articles/03-build/2023-11-02-以月访问量760万的字数统计工具网站告诉你为什么要用关键字为域名.md)）。

背后的理由，哥飞在 [为什么要一个关键词一个域名？](../articles/03-build/2024-01-29-【哥飞解读】为什么要一个关键词一个域名？.md) 里讲过：谷歌排名因素里有一项「细分领域专长」，谷歌更希望一个需求由一个专门做这个需求的网站来满足，而不是靠某个大站的一个内页。所以思路是：**一个关键词一个域名，举全站之力做这一个词**。社群里的刘屹在复盘里也说（[入群九个月，从网站被惩罚到月入万刀](https://new.web.cafe/topic/zi5ps2xpbz)，社群内容），后知后觉觉得「拿关键词做域名」这一点真的很重要，因为后面做的所有页面都是围绕主关键词的。

具体怎么挑，按这个顺序试（来自哥飞「养网站防老第 7 步」的原则，[公众号原文](https://mp.weixin.qq.com/s/B-boMGJsI3bxB8Ih10duRw)）：

1. `关键词.com`，比如关键词是 phone number generator，就试 `phonenumbergenerator.com`；
2. 被注册了，试加横杠的 `phone-number-generator.com`；
3. 还不行，试 `关键词.net`，再试加横杠的 `.net`；
4. com 和 net 都没了，再考虑其他后缀。

几条判断标准：

- **后缀**：哥飞说后缀没有太大关系，`.com .net .org .app .io` 等常用后缀都可以，`.ai` 太贵了；只要不是特别小众、不是特别便宜的后缀就行（[新词来了时，请抓住先发优势](../articles/02-keywords/2025-03-18-新词来了时，请抓住先发优势，尽快发布.md)）。有特定领域惯例的可以跟着走，比如很多游戏站用 `.io`，哥飞做记忆力游戏时就选了 MemoryTest.io。
- **横杠**：带不带横杠都没关系，带横杠的也有大流量网站；有不带横杠的选择时，一般选不带的。
- **有没有被人用过**：如果你买的是别人过期不续费的老域名，先去 archive.org 看看它以前是干什么的。哥飞分析过一个两个月拿下 1359 万访问、随后被谷歌 K 掉的网站，它的域名就是 2022 年没续费、2023 年被人重新注册的老域名（[两个月拿下1359万访问量的新网站为什么会被谷歌给K了？](../articles/05-ranking/2023-10-19-哥飞解读：两个月拿下1359万访问量的新网站为什么会被谷歌给K了？.md)）。第一个站建议直接买全新域名，少一个变量。
- **cc 这类小众后缀有坑**：哥飞提到过有些后缀（比如 cc）即使 sitemap 能访问、格式也正确，GSC 就是提示无法抓取（[GSC 提示站点地图无法抓取怎么办](../articles/05-ranking/2025-07-22-【哥飞SEO教程】Google-Search-Console-提示站点地图-Sitemap-无法.md)）。这是又一个优先选常用后缀的理由。

新词的域名要抢。社群里的王马扎做一个新词站时，`.com .ai .net` 都已经被人注册了但还没上线，他花 2 美元注册了一个 `.art`，照样做出了流量（[他的复盘](https://new.web.cafe/topic/xmsohbemzf)，社群内容）。意思是：好后缀没了不代表这个词不能做，别为此卡住。

### Step 2：想清楚用主域名、子目录还是子域名

第一个站几乎都是「一个新域名 + 首页做主关键词」，这一步很快。但以后你会碰到「这个新需求要不要放在老站里」的问题，所以先把规则记住。哥飞在 [从一个月访问量7.8亿的网站告诉你子域名和子目录该如何选择](../articles/04-onpage/2023-09-19-从一个月访问量7.8亿的网站告诉你子域名和子目录该如何选择.md) 里讲的是：

- **子目录**（`example.com/dog/`）之间一般是兄弟关系，用来做主关键词下面的二级、三级词。首页优化主关键词，一级子目录优化一级词，二级子目录优化二级词。
- **子域名**（`dog.example.com`）可以认为是一个全新的网站，适合和主站业务上没关系的关键词。例子是 fandom.com，哈利波特和火影忍者各有一个子站，每个子域名优化一个关键词。
- **两个毫不相关的需求**，按「一个关键词一个域名」直接注册两个域名。

多语言是另一回事：哥飞建议新站用子目录（`/ja/`、`/fr/`）做多语言，冷启动成本更低，连 Canva 这样的大站也是用子目录（[用几个案例来讲解程序化SEO](../articles/04-onpage/2024-09-13-【哥飞小课堂】用几个案例来讲解程序化SEO生成海量页面获取流量的方式.md)）。多语言放到下一章细讲。

### Step 3：在国外注册商买域名

哥飞的说法是：域名**哪个平台买都行，只要不是国内买**，价格相差不大，没必要为几块钱折腾。他在 [【5800字长文】从网站站内优化到部署上线再到推广运营](https://mp.weixin.qq.com/s/eM1vquYr87hYfgM5JYY6HA) 里列过几个国外注册商：GoDaddy、Namecheap、NameSilo、Porkbun、Cloudflare、Hostinger，「随便哪个都可以，你有哪个账号就在哪里注册」。

操作：

1. 打开注册商官网，在搜索框输入你想要的域名，看是否可注册、首年价格和续费价格。**注意续费价**，有些后缀首年便宜续费贵。
2. 加入购物车付款。注册信息按真实情况填，一般注册商会默认提供隐私保护（以各家说明为准）。
3. 付款后在「我的域名」里能看到它，就完成了。

### Step 4：把域名的 DNS 交给 Cloudflare

域名买好后，哥飞建议统一用 Cloudflare 做域名解析（[说说域名 NS 和 DNS](../articles/03-build/2024-02-24-【哥飞科普】说说域名-NS-和-DNS.md)）。先理解两个词：

- **DNS** 是把域名和服务器 IP 对应起来的系统；
- **NS**（名称服务器）是 DNS 的一部分。注册商默认给你用它家的 NS，用 Cloudflare 就要把 NS 换成 Cloudflare 给的两个地址。

操作（界面可能改版，以 Cloudflare 当前界面为准）：

1. 登录 Cloudflare，添加一个站点（Add a site / 添加域），输入你的域名，选择免费套餐。
2. Cloudflare 会扫描已有解析记录，新域名是空的，直接继续。
3. 页面会给出**两个** NS 地址，复制下来。
4. 回到注册商后台，找到这个域名的 DNS / Nameservers 设置，改成自定义，把两个地址填进去，保存。
5. 回到 Cloudflare 等待生效。「待处理」「未激活」的状态不用管；哥飞演示时等他去 GitHub 建完仓库、生成完代码回来，状态已经变成可用了。

哥飞「养网站防老第 7 步」里还让开启三个选项：Automatic HTTPS Rewrites、Always Use HTTPS、Brotli。其中 **Always Use HTTPS 就是让 http 自动跳到 https**，这是上线必须有的。

### Step 5：选技术路线——页面内容必须在 HTML 里

这是整章最重要的一条技术要求：**网页主体内容必须跟随 HTML 代码一起返回**，也就是服务端渲染或静态页面，不能是「先返回一个空壳、再用 JavaScript 把内容画出来」的纯前端渲染。

哥飞在 [如果不想要谷歌给的免费流量，你就用前端渲染吧](../articles/05-ranking/2024-04-07-【哥飞SEO教程】如果不想要谷歌给的免费流量，你就用前端渲染吧.md) 里说：谷歌爬虫抓取 HTML 代码后一般不会运行 JS，而是直接提取网页主体内容；有人说谷歌也能渲染 JS，但运行代码要额外消耗算力，谷歌凭什么给我们的小网站耗费这个资源？所以「别做他想，赶紧改成后端渲染吧」。很多人是开发前没跟工程师说清楚，上线了一个前端渲染的网站，最后只能返工。

**自查方法**（现在就记住，每个站上线都要查）：

1. 用 Chrome 打开你的网页，在空白处右键，选「查看网页源代码」；
2. 按 Ctrl+F（Mac 是 Cmd+F），搜页面上显示的一句正文；
3. 搜得到、而且在 HTML 标签里 → 合格；搜不到，或者只出现在一大段 JSON 数据里 → 算前端渲染，要改。

按你的情况选路线：

**路线 A：纯静态 HTML（第一个站推荐）。** 一个 `index.html` 就是一个网站，天然满足上面的要求。哥飞的记忆力游戏站、Threads 介绍站都是这样上线的。适合单页工具、小游戏、单页内容站。

**路线 B：Next.js 这类支持服务端渲染的框架。** 哥飞说 Vercel 官方支持的 Next.js 是 SEO 友好的前后端 JS 框架，很值得学（[可以帮你赚钱的 Next.js 教程和开源项目推荐](../articles/03-build/2024-01-09-可以帮你赚钱的-Next.js-教程和开源项目推荐.md)）。他常用的组合是 **Next.js + TailwindCSS + Shadcn/UI，部署到 Vercel**，前后端服务器啥都不用管（[产品经理再也没有借口不会写代码了](../articles/03-build/2024-08-17-产品经理再也没有借口不会写代码了，再也不会就缺一个程序员了.md)）。要做多页面、登录、支付的站，走这条。注意 Next.js 也能写成前端渲染的页面，上线后照样用上面的方法自查。

**路线 C：开源项目或模板改一改。** 哥飞推荐过一些 SEO 友好、能一键部署到 Vercel 的开源项目，比如 AstroPaper 博客模板——「看中了某个关键词，注册了域名，就可以立马用这个博客站源码，先快速上线第一版网站」（[分享两个SEO友好的开源网站](../articles/03-build/2023-12-27-分享两个SEO友好的开源网站，一个内容站，一个工具站.md)），还有他自己开源的 GitBase 导航加博客程序（[如何10分钟快速上线一个导航加博客网站](../articles/03-build/2024-08-12-哥飞教你如何10分钟快速上线一个导航加博客网站.md)）。用别人的项目，先确认许可证允许商用，再把内容全部换成你自己的。

**路线 D：WordPress。** 不写代码也能上站。哥飞介绍过产品经理范尼 gogogo 白天上班、晚上上站，用 WordPress 三个月做了几十个站（[3个月30个站：不写一行代码如何 2 小时快速上站](../articles/03-build/2024-06-10-3个月30个站：不写一行代码如何-2-小时快速上站.md)）。WordPress 需要主机，不在本章的免费托管路线里，想走这条请另找对应教程。

### Step 6：用 AI 生成第一版页面（给非程序员的路线）

不会写代码没关系。哥飞的体会是：「如果你不会编程，但是懂大概一些技术名词，只要能够描述清楚需求」，AI 就能帮你写代码。第一个站按下面做：

1. **先想清楚页面要回答什么**。去谷歌搜你的关键词，看前几名长什么样，用户是来找工具、找信息还是找游戏（下一章细讲）。
2. **让 AI 生成页面**。把需求一次说清楚：用什么技术（比如纯 HTML + TailwindCSS，一个文件）、核心功能、页面要有哪些区块、文案用英文、围绕哪个关键词写。可以参考哥飞做记忆力游戏时的两段提示词：第一段只让 Claude 写游戏本身（`game.html`，纯 html+css+js，写清规则和计分），第二段让它做首页 `index.html`：「生成英文界面……围绕着关键词 Memory Test 去编写页面内容，详细介绍游戏规则，游戏玩法，计分方式……需要有落地页常见的各种 Section，最终全部 Section 组成了 SEO 友好的 Headings」。
3. **一定写明语言**。哥飞第一段提示词忘了说要英文，生成了中文游戏，「将错就错」先发了中文版——你可以避开这个坑。
4. **在 AI 的预览里自己用一遍**，确认核心功能能用，再复制代码。
5. **放进 GitHub**。GitHub 上新建一个仓库（可以用域名当仓库名），直接在网页上「Add file → Create new file」，文件名填 `index.html`，粘贴代码，点 Commit changes。不会用 git 命令行也能完成，哥飞的半小时教程就是全程在线操作的。

刘小排的做法更省事：用 bolt.new 这类在线工具，一段提示词写清技术栈、核心功能、页面区块（header、hero、features、how it works、faq、footer 等）、文案要求和风格，几分钟出一个能用的站（[刘小排：5分钟做个网站，人人都能学会](../articles/03-build/2024-11-13-刘小排：5分钟做个网站，人人都能学会.md)）。这类工具的服务状态和收费经常变，用哪个以当时情况为准。之后要持续迭代，可以换到 Cursor 这类 AI 编辑器里改。

### Step 7：部署到 Vercel 并绑定域名

以哥飞教程里最常用的 GitHub + Vercel + Cloudflare 组合为例（Vercel 界面会改版，按钮名称以当前界面为准）：

1. 用 GitHub 账号登录 Vercel。哥飞提醒过：**全新注册的 GitHub 账号去注册 Vercel，很可能刚注册就被封**，这时发邮件给客服证明你是真人就能解封。
2. 点 Add New → Project，选中你的仓库，点 Import。纯静态页面什么都不用改，直接点 Deploy。
3. 部署成功后，Vercel 会给一个 `xxx.vercel.app` 的测试域名，先打开看看能不能访问。
4. 进项目的 Settings → Domains，输入你的域名，点 Add。Vercel 会问你要不要把 www 和不带 www 的都加上、谁跳转到谁——**选一个做主域名，另一个 301 跳过去**。哥飞自己习惯用不带 www 的裸域名做主域名（[再聊 Canonical 标签](../articles/04-onpage/2024-05-16-【哥飞SEO教程】再聊-Canonical-标签，用好有好处，用错有坏处，需要小心用.md)），选哪个都行，关键是只留一个。
5. Vercel 会给出需要添加的解析记录，一般是一条 A 记录（裸域名）、一条 CNAME 记录（www）。到 Cloudflare 的 DNS → Records 里按它给的值逐条添加。如果已有同名记录提示冲突，判断旧记录不需要就删掉。
6. 回到 Vercel，等它检测到记录并生成 SSL 证书。
7. **Cloudflare 的 SSL/TLS 模式改成「完全（Full）」或「完全（严格）」**。哥飞两次演示里分别用过这两个，半小时教程里选的是完全（严格）。如果停留在默认的「灵活（Flexible）」，打开网站会一直提示**重定向次数过多**。
8. 用 `https://你的域名` 打开，能看到页面，部署完成。

以后你在 GitHub 里改了代码提交，Vercel 会自动重新部署。哥飞说这样你的电脑和 GitHub 各存一份原始网页，哪天某个托管平台不能用了，换个平台部署、改一下解析就行。

不想用 Vercel 的话，哥飞也提过前端可以用 Cloudflare Pages，后端可以用 Cloudflare Workers，两家的免费套餐起步够用，流量上来了再付费（截至 2026 年 9 月的情况，额度与条款以官方最新为准）。

### Step 8：上线当天必做清单

网站能打开只是一半。下面这些，**上线当天一次做完**，不要拖。

**① 检查跳转：只有一个网址能访问首页。** 依次在浏览器里打开这四个地址：`http://域名`、`http://www.域名`、`https://域名`、`https://www.域名`，最后都应该停在你选的那一个主网址上。http 跳到 https 是正确的——以后 GSC 里看到「网页会自动重定向」这类提示不要慌，哥飞的原话是「GSC 只是提示，不包含对错判断」，跟你预期一致就不叫报错（[GSC 提示 HTTP 会跳转到 HTTPS 不要慌](https://new.web.cafe/tutorial/detail/95yrjevk8v)，社群内容）。王马扎就踩过反面的坑：没做 http 到 https 的 301，GSC 里 http 和 https 两个版本同时出现在搜索结果里。

**② 每个页面写好 canonical。** 在 `<head>` 里加一行 `<link rel="canonical" href="https://你的主网址/当前页面路径">`，指向**当前页面自己**的规范网址。不要全站都写成首页（下一章细讲）。

**③ 放 robots.txt。** 在网站根目录放一个 `robots.txt`，第一个站最简单的写法是全部允许抓取，并写上 sitemap 地址：

```
User-agent: *
Allow: /

Sitemap: https://你的域名/sitemap.xml
```

哥飞的原则是：**所有不是拿来获取流量的页面，都不应该被抓取**（比如后台、登录后的页面）。用 `Disallow:` 一行行写出来，多语言站要为每种语言各写一行（[多语言网站 robots.txt 设置指南](../articles/04-onpage/2024-08-10-【哥飞SEO教程】多语言网站-robots.txt-设置指南：如何正确阻止不希望被抓取的页面.md)）。用 Next.js 的话可以用框架自带的 robots 文件约定动态生成。

**④ 放 sitemap.xml。** 列出你所有想被收录的页面网址。格式不会写就让 AI 按你的页面列表生成，或用框架自带的 sitemap 生成功能。放好后在浏览器打开 `https://你的域名/sitemap.xml`，确认能访问、网址用的是主域名和 https。

**⑤ 装统计代码。** 打开 Google Analytics，新建媒体资源 → 平台选「网站」→ 填域名和网站名 → 创建数据流，拿到统计代码，放到**每一个页面**里。GA 官方给的位置是 `<head>` 里；哥飞「养网站防老第 8 步」的做法是放在 `</body>` 之前，理由是统计服务万一加载不出来也不拖慢网站（[公众号原文](https://mp.weixin.qq.com/s/lCy2pWnFuP2riO9H0mJbIg)）。哥飞也推荐可以同时装微软 Clarity（[新词来了时，请抓住先发优势](../articles/02-keywords/2025-03-18-新词来了时，请抓住先发优势，尽快发布.md)）。装完后自己打开网站，看 GA 的实时报告里有没有你这 1 个访客。

**⑥ 添加到 GSC 并提交 sitemap。** 在谷歌里搜 `site:你的域名`，结果页会有进入 Search Console 的入口；也可以直接打开 search.google.com/search-console。添加资源时选「网域」，输入域名。域名在 Cloudflare 上的话可以一键授权验证，否则按提示加一条 TXT 解析记录。验证后在左侧「站点地图」里填 `sitemap.xml` 提交。（哥飞 [GSC 入门讲解](https://mp.weixin.qq.com/s/bETdv9x1Ytozi49Nfm-l6g)）哥飞也提醒过：GSC 只能看到网站在谷歌的表现，想看 Bing 要另外去 Bing 站长后台。收录相关的细节在[第 5 步](./07-第5步-收录：让谷歌把页面收进去.md)讲。

**⑦ 补基础页：About、Contact、Privacy、Terms。**

- **About**：这个网站是做什么的、谁做的；
- **Contact**：留一个邮箱或联系表单；
- **Privacy Policy**：你收集了什么数据（装了 GA 就有 Cookie 和访问数据）；
- **Terms of Service**：使用条款。

群友布衣在复盘里写过：隐私政策、服务条款、支付和退款政策、Cookie 政策，在申请收款账户时能当证明材料，遇到争议时也是证据；网站上要留联系方式，让用户有问题时能找到你，避免直接向银行投诉欺诈；他最早用 Paddle 收款时，开通审核就要求网站有定价、隐私政策、服务条款、支付和退款政策页面（[布衣：工具站出海，月入3000刀，记录下这一年踩过的那些坑](../articles/12-community/2025-08-26-布衣：工具站出海，月入3000刀，记录下这一年踩过的那些坑（7500-字）.md)）。哥飞讲 AdSense 申请时也说，审核看的是「像一个正规的、正式的、完善的、多页、有优质内容和服务网站」，而不是一个随便糊弄的单页网站。这几页让 AI 按你的实际情况生成，再自己读一遍，把不符合事实的地方改掉（法律文本的具体要求以你所在地和收款平台的规定为准）。在页脚放上这几页的链接。

**⑧ 用手机打开一遍。** 看看布局有没有乱、核心功能能不能用。

做完这八项，网站就算真正「上线」了。

## 常见坑

- **Cloudflare SSL 选了「灵活」**：打开网站一直「重定向次数过多」。改成「完全」或「完全（严格）」。
- **新 GitHub 账号注册 Vercel 被封**：发邮件联系客服说明你是真人。
- **做成了前端渲染**：页面看着正常，谷歌却抓不到内容。开发前就要求服务端渲染或静态输出，上线后用「查看网页源代码」自查。
- **多个网址都能打开同一页面**：www 和裸域名、http 和 https 都能访问又没有跳转，在搜索引擎眼里就是一堆重复网页。选一个主网址，其余 301。
- **憋大招**：想把登录、支付、多语言、几十个页面全做好再上线。哥飞原话：「有比没有好，完成比完美更重要，请尽快上线第一版」。王马扎复盘说自己有一个多月「陷入了完美主义」，那个产品最后也没上线，他的经验是一个网站从开始开发到上线第一个版本最好不要超过 2 个星期。
- **在国内注册商买海外站的域名**：哥飞明确说过尽量不要。
- **sitemap 提交失败**：常见原因是拿网页地址当 sitemap 地址提交、sitemap 放错目录访问不到、格式错误、GSC 里的域名与 sitemap 里的域名不一致。逐个排查（[GSC 提示站点地图无法抓取怎么办](../articles/05-ranking/2025-07-22-【哥飞SEO教程】Google-Search-Console-提示站点地图-Sitemap-无法.md)）。
- **复用老站代码带出了多余页面**：王马扎用有流量那个站的代码上了一个新站，隐藏了语言切换按钮，但多语言网址仍被谷歌收录，两个域名出现了相同内容。复用模板时，把不需要的路由真正删掉，而不是只藏按钮。

## 完成检查清单

- [ ] 域名是关键词（或关键词加横杠），常用后缀，在国外注册商购买
- [ ] 域名 NS 已切到 Cloudflare，状态为已激活
- [ ] 代码在 GitHub，部署在 Vercel（或 Cloudflare），`https://域名` 能打开
- [ ] 「查看网页源代码」能搜到页面正文
- [ ] http / https、www / 裸域名四个地址最终都跳到同一个主网址
- [ ] Cloudflare SSL 模式为「完全」或「完全（严格）」
- [ ] 每个页面有指向自身的 canonical
- [ ] `robots.txt` 和 `sitemap.xml` 都能在浏览器打开
- [ ] GA（或 Clarity）已安装，实时报告能看到自己
- [ ] GSC 已验证网域，sitemap 已提交
- [ ] 有 About、Contact、Privacy、Terms 页面，页脚有链接
- [ ] 手机上打开检查过一遍
