# 开始之前：心态、时间与成本

前两章回答了「为什么做」和「现在还能不能做」。这一章回答「开始之前要准备什么」：用什么心态做、每周要拿出多少时间、要花多少钱、哪些账号要先注册好，以及你到底适不适合做这件事。

这些东西看起来不如找词、建站那么「干货」，但很多人不是倒在技术上，而是倒在预期上：以为第一个站就能爆，没爆就放弃；以为每天抽半小时就够，结果一个月一个站都没上线；或者一开始就把钱花在用不上的地方。

**做完这一章的标准**：你给自己定好了前三个月的目标（不是收入目标，是练手目标）；在日历上排好了每周固定的做站时间；列好了一份启动预算，知道哪些钱现在花、哪些以后再花；Google 账号等基础账号已经注册好；你对「我适不适合」有一个诚实的答案。

## 你需要准备

- **时间**：读完本章约 30 分钟；排日程、列预算、注册账号约 1~2 小时。
- **一个日历**（手机日历即可）。
- **一个表格或笔记文档**，用来记预算和之后每个站的复盘。
- **一个手机号和一张能付外币的银行卡**：注册部分海外服务、买域名时可能用到。具体支持哪些卡以各平台当时的说明为准。

## 步骤

### Step 1：放弃「一站发」，把前三个站定成练手站

哥飞在 [放弃一站发思维，先从练手站做起](../articles/01-direction/2024-12-02-放弃一站发思维，先从练手站做起.md) 里说，看多了群友的成功案例，就想做一个网站立马爆发、赚大钱，「这跟你去买张彩票，然后幻想中大奖，一夜暴富的心理是一样的」。他给新人的路线是三个练手站，难度逐级往上：

1. **第一个站：不看任何关键词。** 自己想一个独一无二的网站名，注册域名，走完上站全流程，最后能在谷歌用这个名字搜到你的网站。这个站不会有流量，但你会学会注册和解析域名、部署网站、加统计代码、提交 GSC、判断有没有被收录。
2. **第二个站：选一个几乎没人竞争、但有别人在搜的词。** 搜索量每天只有几十都没关系。用谷歌直接搜、用 `intitle:` 搜，确认没多少人做；用这个词注册域名、做网站；被收录后加几个外链，看着排名往前走。这个站用来学加外链。
3. **第三个站：选没人竞争、每天有几百搜索量的词。** 加内页、加外链，如果也能上谷歌首页，「此时，你就走出新手村了」。

另一篇 [【哥飞解答】第一个出海站，要做什么？要怎么做？](../articles/01-direction/2024-01-24-【哥飞解答】第一个出海站，要做什么？要怎么做？.md) 给了更具体的门槛：第一个站目标是「一是要上线，二是要进入搜索结果前10」，找 Ahrefs 难度小于 10、所需外链网站数也小于 10 的词，「不要去关心搜索量」；第二个站争取每天 100 个来自谷歌的点击；第三个站争取每天 1000 个以上。

哥飞还给过三个「毕业门槛」，你可以拿来当长期的刻度尺（[为什么我们应该多做网站？](../articles/10-scale/2025-07-10-为什么我们应该多做网站？当然是为了多赚美元！.md)）：

| 门槛 | 标准 | 哥飞估计的时间 |
| --- | --- | --- |
| 走出新手村 | 做的所有产品收入加起来超过 1000 美金 | 短则两三个月，长则六七个月 |
| 毕业 | 新做一个网站，上线第一个月就赚 1000 美金以上 | 短则五六个月，长则一年 |
| 学有所成 | 多个网站加起来月收入稳定 1 万美金 | 短则半年一年，长则不超过两年 |

这些时间是哥飞根据社群经验给的估计，不是承诺。有人快很多，也有人更慢——王马扎的原话是「从0刀到0.01刀花了4个月，从0.01刀到1000刀花了15天」（[摘要](../stories/02-wangmazha.md)）。

**现在就做**：在笔记里写下你前三个站的目标，照抄上面的第 1、2、3 条即可。第一个站的目标里不许出现「赚钱」两个字。

### Step 2：接受「数量胜于质量」，但每个站都要复盘

哥飞引用过一个故事：佛罗里达大学摄影课把学生分成「数量组」和「质量组」，学期结束时所有最佳照片都来自数量组（[数量胜于质量，不要憋大招](../articles/10-scale/2025-07-18-【数量胜于质量，不要憋大招】佛罗里达大学教授的试验结果，与哥飞的实践经验不谋而合.md)）。他的结论是：「作为初学者，我们没必要追求完美，我们没必要憋大招，我们要做的是尽可能多的练习。」

群友的真实数字也在说明这一点：

- 井然做了十多个域名、不少半成品，「第三个 AI 工具站」上线一周左右开始有人下单（[摘要](../stories/04-jingran.md)）。
- 金鱼Evan 做了 30 多个站，「很多人只看到最后 Nano Banana Pro 那一下，但前面这些站更像练习量——你练得越多，机会来了越不慌」（[摘要](../stories/05-jinyu-evan.md)）。
- Fiona 的说法是「做的站足够多，总有能起来的——这是大数定律，不是鸡汤」，每个站都是独立的，「失败了就失败了，记录一下，继续下一个」（[摘要](../stories/08-fiona.md)）。

但数量有一个前提：**每做完一个站都要复盘，把教训带到下一个。** 哥飞说得很直白：「同样的经验去做十几个网站，这样是没用的。你想碰运气，可是运气并不会青睐敷衍的人。」（[入群四个月实现月入万刀，底气从哪来？](../articles/12-community/2025-11-14-入群四个月实现月入万刀，底气从哪来？.md)）另一篇里他也强调「努力一定不是盲目追求数量」（[成功率有多大，其实不看我](../articles/00-why/2025-07-31-成功率有多大，其实不看我，看你自己，看你自己有多努力.md)）。

还有一个与「数量」相关的概念你以后会遇到：**饱和式建站**——看中一个关键词，注册几个域名都围绕它建站，争取在搜索结果第一页占几个位置（[什么是饱和式建站？](../articles/10-scale/2023-10-26-什么是饱和式建站？为什么要饱和式建站？怎么实现饱和式建站？.md)）。注意哥飞的提醒：每个站的布局、代码、内容都必须不一样，复制粘贴 10 份上线「一定会被谷歌发现，然后被K」。这是走出新手村之后的打法，第 11 步会讲，现在知道有这回事就行。

**现在就做：建一张复盘表。** 金鱼Evan 的做法是建「问题库」，每个坑按「问题—原因—解决方式—分类」记下来，上线前从头过一遍（[摘要](../stories/05-jinyu-evan.md)）。你可以在表格里给每个站开一行，至少记这些列：

| 列 | 例子 |
| --- | --- |
| 关键词 / 需求 | 一句话说清这个站解决什么 |
| 域名、上线日期 | |
| 第几天被收录 | 用 `site:你的域名` 在谷歌查 |
| 第 7 / 30 天的曝光和点击 | 从 GSC 抄 |
| 收入 | 没有就写 0 |
| 做对了什么 | |
| 做错了什么、下次怎么改 | 这一列最重要 |

### Step 3：算清楚你每周有多少时间，然后排进日历

哥飞在 2023 年按「兼职」算过一笔时间账（[新人出海建站从找到需求做出网站到成功变现跑通闭环大概要多久？](../articles/00-why/2023-11-18-新人出海建站从找到需求做出网站到成功变现跑通闭环大概要多久？.md)）：

- 假设每天下班后拿出 **2 小时**，每个周末拿出 **10 小时**，一周约 **20 小时**。
- 如果你懂前后端：花一周学概念并挖掘需求，一周开发，一周宣传推广；第四周开始，如果词选对了才有可能拿到流量；「一切都正常稳定推进的情况下，在第五周能够赚到第1美元」。
- 不是全栈、边学边做，「这个时间还得再加一两周」。
- 完全不懂开发，他建议用 WordPress 搭内容博客，「四周左右，能够拿到正反馈」。
- 第一个站跑通之后，「第二个网站就会省去一半的时间」。

这是 2023 年的估算。现在有 AI 编程工具，开发那一周可以大幅缩短——慎独第一个站让 AI 写静态页「两小时上线」（[原文](https://new.web.cafe/topic/wr0cxwogic)）。但找需求和推广的时间，AI 省不了多少。

**时间怎么分？** 哥飞提过一个 424 原则：「用40%的时间来挖掘需求，来判断需求是否可以做，用 20% 的时间快速开发第一版，用 40% 的时间来宣传推广」（[主动离开大厂，下海猛干一个月，拿到正反馈了](../articles/12-community/2025-07-14-主动离开大厂，下海猛干一个月，拿到正反馈了.md)）。井然严格执行 424 之后，第三个站两天上线、一周左右出单（[摘要](../stories/04-jingran.md)）。程序员最容易犯的错是把 80% 的时间花在写代码上。

**上班族怎么排？** 下面是按「每周 20 小时 + 424 原则」给出的一个参考排法，不是哥飞的原话，你按自己的作息调整：

| 时间 | 做什么 | 对应 424 |
| --- | --- | --- |
| 周一到周五，每晚 1 小时 | 刷 Google Trends、看竞品、记候选词 | 找需求（40%） |
| 周一到周五，每晚另 1 小时 | 看已上线站的 GSC 数据，发外链、提交导航站 | 推广（40%） |
| 周六 | 选定一个词，开发并上线（有 AI 辅助，一天够做出第一版） | 开发（20%） |
| 周日上午 | 上线收尾：接 GSC、GA，提交收录，发第一批外链 | 推广 |
| 周日下午 | 填复盘表，定下周要看的方向 | 复盘 |

几条实际经验：

- **新词不等周末。** 孟健团队的铁律是「当天发现的新需求，必须当天上线」（[摘要](../stories/12-mengjian.md)）；慎独中午 11 点 50 买域名，让 AI 写页面部署上去，「然后就去上班了」。所以平时最好准备一套能快速改改就上线的模板代码。
- **集中精力做一件事。** 诗意听涛的「N 日计划」是花 3~7 天集中只做一件事，比如「单独为外链花费3天」，而不是每天列七八件事、每件都做一点（[原文](https://new.web.cafe/topic/eh1bh3b551)）。
- **买时间、攒时间。** Fiona 的办法是：舍得花小钱把不值得亲自做的事外包，把发外链、找词这些重复工作交给工具；「AI 生成内容的时候，自己去找下一个词」（[摘要](../stories/08-fiona.md)）。
- **时间少就收缩战线。** 在职开发者 Flicker 没时间追新词，就把精力集中在有反馈的站上，持续迭代老站，连续 3 个月订阅收入千刀左右（[摘要](../stories/11-flicker.md)）。
- **别长期透支。** 哥飞写过一位群友「每天下班后搞到两三点甚至三四点，然后七八点又起来上班」，几个月后副业收入超过主业（[原文](../articles/00-why/2025-07-31-成功率有多大，其实不看我，看你自己，看你自己有多努力.md)）。能这样拼的人有，但不是人人都该学。droidHZ 的提醒是：「长期没结果影响心态很正常，可以适当停下、调整、再轻装上阵」（[摘要](../stories/10-droidhz.md)）。

**现在就做**：打开日历，把下周的做站时间按块排进去，设成每周重复。算一下你一周实际能拿出几小时，写在复盘表第一行。如果少于 10 小时，把第一个站的完成时间预期放宽一倍。

### Step 4：列一份启动预算

好消息是：做出海网站的启动成本很低。哥飞拆过一个网站的成本——域名「一年几十块钱，几乎也可以忽略不计」，服务器用 Vercel 和 Cloudflare「也几乎没啥成本」，营销靠 SEO「几乎没成本」（[大厂看不上，大厂员工看不懂](../articles/00-why/2025-01-24-大厂看不上，大厂员工看不懂，这就是我们的机会.md)）。

真实账本更有参考价值。慎独在 2026 年 3 月做第一个站（新词站，一个月内累计收入 2000 美元）时，把花销摊开列了出来（[原文](https://new.web.cafe/topic/wr0cxwogic)）。下表摘录其中和做站相关的几项，他账里的学习费用这里不列：

| 项目 | 慎独的实际花费 | 说明 |
| --- | --- | --- |
| AI/API 调用 | ¥1,325 | |
| 工具/模版 | ¥1,133 | |
| 外链 | ¥830 | 他在 Upwork 上「$110买2条」 |
| 海外公司 + Stripe | ¥4,300 | 为了接订阅收款，**不是第一天就需要** |
| 服务器 + 域名 | ¥430 | |

结合其他来源，下面是一份按「第一天就要」和「以后再说」分开的预算清单（金额是量级，价格随时会变，截至 2026 年的群友实践，请以各平台当时报价为准）：

**第一天就要：**

- **域名**：每个站一个。常见后缀一年几十元人民币的量级（哥飞的说法）；也有人用更便宜的后缀起步，比如布衣第一个站「只花 15 元买了一个 .xyz 域名」，王马扎「用 2 美元注册 .art 域名抢下的新词」（[布衣](../stories/13-buyi.md)、[王马扎](../stories/02-wangmazha.md)）。注意很多后缀首年便宜、续费贵，买之前看清续费价。为什么建议用关键词做域名，见 [第 3 步](./05-第3步-建站上线.md)。
- **托管**：Vercel、Cloudflare Pages 这类平台对小流量站基本免费，droidHZ 说「Vercel 的免费额度足够用了……当你真正赚到钱，自然会愿意去折腾」（[摘要](../stories/10-droidhz.md)）。但要留意默认开启的付费功能：群友蒋子豪 2026 年 4 月记录过，一个每天真实访客大概 50 人的新站，账单上「花了 $13」，原因是默认开着的按用量计费功能、缓存失效、大量页面频繁刷新缓存（[我在 Vercel 上交了一笔学费](https://new.web.cafe/topic/ctygfhjq9x)）。上线后 48 小时内看一眼账单。
- **AI 编程工具**：一个主流 AI 编程工具的订阅。这是现在做站提速最明显的一笔钱，具体选哪家、多少钱以官方为准。

**可以先不花，需要时再花：**

- **SEO 工具**：初期用免费版就够。哥飞推荐的免费组合是 AITDK 插件加 Ahrefs 的几个免费工具（[程序员为什么要出海赚美刀？](../articles/00-why/2025-07-03-程序员为什么要出海赚美刀？程序员如何搞副业做网站赚美元？.md)）。Semrush、Similarweb、Ahrefs 正版都不便宜，哥飞 2023 年提到他订阅的 Similarweb 高级版「费用差不多11000元一年」（[与其国内卷，不如出海浪](../articles/00-why/2023-12-18-与其国内卷，不如出海浪.md)），新人完全没必要。
- **外链**：先做免费的，比如把网站提交到各类导航站，「去各个 AI 导航网站提交一遍，就有几十个上百个外链」（[如何赚到你的第一美元](../articles/00-why/2024-06-20-哥飞教你如何赚到你的第一美元？.md)）。新词站需要的外链少；做老词、拼排名时才需要花钱买，那是另一个量级（第 7 步讲）。
- **付费 API**：做 AI 工具站才需要。孟健提醒过 API 成本会失控，排队状态每小时烧掉 1~2 美元（[摘要](../stories/12-mengjian.md)）。先做不花 API 钱的站练手。
- **海外公司、支付账户**：要接订阅收款时再办，详见 [第 10 步：收款](./12-第10步-收款：把钱拿到手.md)。广告变现（AdSense 等）不需要公司。
- **广告投放**：新人不建议一开始就投。

**现在就做**：照上面的清单，在表格里列出你前三个月的预算，分「必须」和「以后」两栏。练手阶段的「必须」一栏，通常就是几个域名加一个 AI 工具的订阅。

### Step 5：把基础账号先注册好

下面这些账号，上站当天都会用到。提前注册、提前熟悉界面，能省掉上线时手忙脚乱的时间。慎独说他之所以能在流量来的那一刻立刻看到数据，是因为「部署完就顺手关联上了」GSC 和 GA（[原文](https://new.web.cafe/topic/wr0cxwogic)）。

1. **Google 账号**（Gmail）。后面所有谷歌的服务都用它登录。建议专门注册一个做站用。
2. **Google Search Console（GSC）**：谷歌站长后台，看网站有没有被收录、在哪些词上有曝光和点击。现在还没有网站，先登录进去看看界面即可，上线时再添加网站。怎么用见 [第 5 步：收录](./07-第5步-收录：让谷歌把页面收进去.md) 和 [第 8 步：看数据](./10-第8步-看数据：判断做得对不对.md)。
3. **Google Analytics（GA4）**：统计网站有多少访客、从哪里来、停留多久。
4. **Google Trends**：不需要注册，但建议现在就开始每天刷一刷，找需求主要靠它。
5. **域名注册商账号**：选一家常用的注册商注册账号，绑好付款方式。
6. **托管平台账号**：Vercel 或 Cloudflare，通常用 GitHub 账号登录，所以也要有一个 GitHub 账号。
7. **一个 AI 编程工具的账号**。
8. **（可选）Bing Webmaster Tools**：必应的站长后台。野生小虎的主词在谷歌下滑时，Bing 和 Yandex 托住了一部分流量（[摘要](../stories/07-yesheng-xiaohu.md)）。
9. **（可选）一个社交账号**，比如即刻或 X（推特）：用来记录过程、找同行交流，以后也是推广渠道。慎独入群时就同步在即刻更新出海记录，第一个广告联盟也是在即刻上看到别人推荐的。

**收款相关先提一句**：广告收入（如 AdSense）和用户付费（如 Stripe、PayPal、Creem）各有各的申请条件和收款方式，有的需要海外公司，有的需要海外银行卡，而且政策经常变。**第一个站不需要急着办这些**，等你的站真的有流量了再办也来得及。详细内容在 [第 10 步：收款](./12-第10步-收款：把钱拿到手.md)。

### Step 6：诚实地判断自己适不适合

**比较适合的人：**

- **每周能固定拿出 10~20 小时，并且能坚持几个月。** 哥飞说：「不是说你花钱进哥飞社群了就一定有回报。而是说你花时间进去了，就一定会有回报。」（[成功率有多大](../articles/00-why/2025-07-31-成功率有多大，其实不看我，看你自己，看你自己有多努力.md)）
- **会编程，或者愿意学着指挥 AI 写代码。** 不会编程的人要做好多花时间的准备（见 [上一章](./00-为什么要出海做网站.md) 第 5 件事）。
- **看得上小钱。** 第一美元、第一百美元都值得高兴，而不是觉得「这么点钱不如上班」。
- **能接受不确定。** 做十个站，可能只有一两个有起色。
- **愿意先照着做。** Fiona 观察到「很多人真正开始起飞，都是从‘不想那么多，先听话照做’开始的」（[摘要](../stories/08-fiona.md)）。

**不太适合的人：**

- **想做一个站就翻身。** 这就是哥飞说的「一站发」心态。
- **只想看不想动手。** 看完一百篇文章不上一个站，等于没学。哥飞的原话是「临渊羡鱼不如退而结网」（[3个月30个站](../articles/03-build/2024-06-10-3个月30个站：不写一行代码如何-2-小时快速上站.md)）。
- **需要这件事在短期内养家。** 王马扎给想入行的人的提醒是：「没有3-6个月打基础的时间，是基本不可能的」，「All In是能力不是选择」（[摘要](../stories/02-wangmazha.md)）。在有稳定收入的情况下业余开始，是大多数人更稳妥的起步方式；不要把生活必需的钱投进去。
- **做着很痛苦，只是因为看到别人赚钱。** Fiona 的原话：「如果你做着很痛苦，不妨认真问问自己：是真的喜欢，还是只是看别人赚钱跟进来的？如果是后者，换个更适合自己的方向不是退缩，是聪明。」

哥飞把出海需要的状态概括成四个词：决心、耐心、细心、平常心（[出海的决心、耐心、细心和平常心](../articles/00-why/2024-12-28-出海的决心、耐心、细心和平常心.md)）。在那篇文章里他还建议你「从现在开始，对自己的时间重新定价」：算一算你下班后和周末的时间，现在是不是一分钱都不值。

## 常见坑

- **完美主义，迟迟不上线。** 王马扎找到一个新词后「陷入了完美主义」，总想做出完美交互，最后产品没上线；他的经验是从开发到第一版上线最好不超过 2 周（[摘要](../stories/02-wangmazha.md)）。
- **只会写代码，不花时间找需求和推广。** 424 原则里开发只占 20%。子昕花大半个月做找词系统，半年还卡在 0 到 1（[原文](https://new.web.cafe/topic/urh3177vi8)）。
- **一开始就买一堆付费工具和服务。** 注册公司、买全套 SEO 工具、买外链，都可以等有流量之后再说。
- **忘了看账单。** 托管平台默认开启的付费功能、失控的 API 调用，都可能在你不注意时扣钱。
- **做了很多站但不复盘。** 同样的错误犯十遍，数量就没有意义。
- **拿单个群友的时间线逼自己。** 慎独入群两天半就拿了第一，Flicker 入群第二年才开始有成果。每个人的起点和投入不同，拿你自己上个月比。
