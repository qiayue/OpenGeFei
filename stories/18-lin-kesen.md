# 第 5 个站撞上新词：GitHub 外链带来大部分流量，AdSense 不到 24 小时通过

> **林克森** · 此前已上线 4 个网站，有自己的建站模板和自动部署流程 · 新词站累计 11 万 UV、70 多万 PV

## 故事

林克森找新词没有取巧的办法：先确定基础词，在 Google Trends 里长期关注，把查询链接存进收藏夹，「有时间了就去看看」。「一下子就找到新词的概率很低，找到了也要交叉去验证准确性。」TA 用 gpts 这个词当基准来比对数量级。

11 月 18 日晚上，TA 习惯性地看谷歌趋势，发现一个特别热的新词，17 日之后趋势和 gpts 基本一样高。去 Google 一搜，还没有相关网站。当时已经晚上 11 点，TA 按哥飞「用关键词做域名」的原则注册了 .com——这个词很长，TA 犹豫过要不要去掉一个单词，最后还是照原则来。

因为之前已经上线过 4 个网站，有现成模板和自动部署流程，大约凌晨一点半网站就上线了。「早上起来，我惊喜地发现流量爆发，几乎没有人在做这个词。」

外链上，TA 注意到群里在讨论 GitHub 权重很高，就在 GitHub 建了仓库和个人主页 README，放上网站链接。「这个GitHub其实是我最成功的举措，后续的流量大部分来自那里。」TA 还注册了 X 和 YouTube 账号，YouTube 也带来了不少流量。后来越来越多人发现这个词，TA 的网站排名逐渐下降，但 GitHub 页面的排名一直保持第一。

三天后申请谷歌广告，「没想到不到24小时就通过了，接着收入增长迅速，一天不到差不多达到了三百美元」。TA 的经验是：流量足够高，审批就会非常快。

后面并不一帆风顺：原作者删掉了游戏工程，流量受损；TA 复刻了一个简版游戏，又被很多人直接复制，只能在 Cloudflare 走 DMCA 举报；之后因为新项目加班，没时间维护，流量开始下滑。统计下来是 11 万 UV、70 多万 PV。TA 自评「外链还是少，网站的内页做的也比较差」，面对竞品保不住排名。

TA 最看重的是积累：「如果没有前面几个网站的积累，我也不可能在发现新词后，那么快上站。」

## 林克森做对了什么

- **长期盯趋势。** 把基础词的 Trends 查询收藏起来，定期查看，用 gpts 当参照。
- **提前备好「武器」。** 前 4 个站沉淀了模板和自动部署，当晚 11 点注册域名，凌晨一点半就上线了。
- **按原则注册关键词域名**，不因为词长而自作主张删减。
- **利用高权重平台。** GitHub 仓库和个人主页 README 成了最主要的流量来源。
- **诚实复盘短板。** 排名下滑的原因是外链质量和内页不够，建站后的运营要跟上。
