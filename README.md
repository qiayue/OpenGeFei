## 关于哥飞

哥飞大学时开始学编程、做网站、学 SEO。毕业后一直在创业和做产品，靠 SEO 拿免费流量的经验攒了很多年；后来在一家游戏发行公司做了几年技术负责人，把付费流量那一套也学会了。

2023 年年中，哥飞开始做出海网站，同时在公众号上把做法一篇篇写出来，也在那年 7 月建了社群「哥飞的朋友们」。这个仓库里的文章，就是哥飞公众号上公开发表过的全部内容。

哥飞的几条核心观点，读教程之前先记住：

- **谷歌的最小排名单位是页面，不是网站。**
- **新手去追热点、追新词；老手去做难而正确的事。**
- **需求是用数据挖出来的，不是拍脑袋想出来的。**
- **别指望一个站就爆，先从练手站做起，多做几个站。**
- **SEO 拿到的流量不要钱，而且可以长期积累。**

## 说在前面

- **这里没有任何收益承诺。** 群友故事里的结果因人而异，大部分人的第一个站赚不到钱，这很正常。
- **平台规则会变。** 教程里涉及支付、广告联盟、平台政策、工具价格的地方都写明了时间，动手前请以官方最新说明为准。
- **想要更多交流和答疑？** 哥飞的社群「哥飞的朋友们」里有更详细的教程、每天的答疑、每月的新词新站比赛和一年两次的线下分享会，介绍见 [new.web.cafe](https://new.web.cafe)。不加入社群，照着这个仓库做也完全可以起步。
