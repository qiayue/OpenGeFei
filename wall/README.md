# 群聊报喜墙

哥飞的社群里，群友做出成绩会在群里说一声。这里把 2023 年 7 月到 2026 年 7 月群聊里的报喜消息收集在一起：

- **560 条报喜**，来自 **344 位群友**
- 其中 **177 位群友**在群里报过自己的第一单或第一笔收入
- 按年份：[2023 年](2023.md) 55 条、[2024 年](2024.md) 110 条、[2025 年](2025.md) 295 条、[2026 年](2026.md) 100 条
- 另外至少还有 **36 位群友**只发了后台截图报喜（发图后几分钟内收到好几条「恭喜」），截图里的内容读不出来，没有算进上面的数字

**实际只会更多**：很多人报喜只甩一张截图不打字；有人在即刻、朋友圈或私聊里报喜；更多人赚到了钱也从来不在群里说。这里收的只是「在群里用文字说出来」的那一部分。

**怎么来的**：先用关键词从群聊原文里筛出候选，再逐条人工判断，只留下「发言人报告自己的一个好结果」的消息；提问、转述别人、祝贺别人、计划和愿望一律不算。

**隐私**：发言人一律匿名；网址、域名、站名、邮箱、微信号都换成了「某站」或删掉。引号里是原话截取，只删不改。

**提醒**：会报喜的是做出了结果的人，没做出来的人不会在群里说。这不是收益承诺，只是让你看到，这条路上每天都有人在往前走。
