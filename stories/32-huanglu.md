# 做站一年后的第一单：三单共 127 美金，也是一份踩坑清单

> **黄璐** · 做完第一个网站已一年，中途因工作忙停过几个月 · 真正做 SaaS 约四个月后开出第一单，后续共三单，合计 127 美金

## 故事

黄璐距离做完第一个网站已经一年了。中途因为工作太忙停了几个月，前期又花了很多时间在导航站、游戏站上，真正开始做 SaaS 只有近四个月。回头看，TA 觉得当初不敢直接做 SaaS 「纯粹是因为不自信」，「干中学就是了，早点开始做SaaS站，说不定能早点赚到第一美金」。

开单之前，有一段 TA 以为网站没人用。「之前一直以为GA的数据含爬虫，GSC的才是真实的。看GSC没几个访问，就以为网站没人用。」直到某天发现 API 已经跑了 100 多美金，TA 还以为网站被黑了、或者 API Key 暴露了，查了半天才明白：其实每天有 200 到 300 访问、5 到 15 个注册，只是注册赠送的积分太多，大家都在免费用。减少赠送积分之后，就开始开单了。

哥飞还问了 TA 一个「灵魂拷问」：「每天来的用户，你知道是哪里来的吗？」「啊？懵圈，我不造啊？」TA 又去现学怎么看用户来源。

还有一个让 TA 心疼的失误：有个用户一个月内买了两次月费，TA 以为系统重复扣费，怕用户吃亏，赶紧手动把订阅设成了到期取消。后来才反应过来，应该先发邮件问用户，「等于亲手把一笔稳定续费的订单给掐断了」。

最后，第一单加上后来的两单，总共 127 美金。「坑踩了就踩了，127美金就当交了学费还赚了顿饭钱。接下来就是——补监控、调积分、管好订阅、别再手欠取消订单了。」

## 黄璐做对了什么

- **别因为不自信绕远路。** 想做 SaaS 就早点做，在做的过程中学。
- **重视数据追踪。** 要看全访问、注册、API 消耗，也要知道用户从哪里来。
- **免费额度要算账。** 注册送太多积分，用户就一直免费用；调整后才开单。
- **订阅问题先问用户**，不要替用户做决定。
- **把踩过的坑写下来**，给刚起步的人提个醒。
