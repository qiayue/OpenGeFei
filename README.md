## 关于哥飞

哥飞大学时开始学编程、做网站、学 SEO，毕业后一直在创业和做产品，靠 SEO 拿免费流量的经验攒了很多年；后来在一家游戏发行公司做了几年技术负责人，把付费流量那一套也学会了。2023 年年中开始做出海网站，同时在公众号上把做法一篇篇写出来，那年 7 月建了社群「哥飞的朋友们」。

哥飞的几条核心观点：

- **谷歌的最小排名单位是页面，不是网站。**
- **新手去追热点、追新词；老手去做难而正确的事。**
- **需求是用数据挖出来的，不是拍脑袋想出来的。**
- **别指望一个站就爆，先从练手站做起，多做几个站。**
- **SEO 拿到的流量不要钱，而且可以长期积累。**
